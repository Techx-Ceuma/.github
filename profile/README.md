### 🧭 Sobre

Organização acadêmica do **TechX**, parceria entre o **Oxygeni Hub** e a **Universidade Ceuma**.
Aqui ficam os projetos das turmas, os laboratórios práticos e o material de apoio das aulas.

> Cada atividade é um repositório. Cada entrega é um commit. Cada revisão é um pull request.

---

### 📚 Trilhas

| Trilha | O que você vai praticar | Status |
|---|---|---|
| **Projeto · Design Thinking** | Imersão, ideação, prototipação e validação com usuários | 🟢 Ativa |
| **Ágil** | Scrum, métricas ágeis, roadmap do produto | 🟢 Ativa |
| **Git & GitHub** | Repositórios, branches, pull requests, GitHub Flow | 🟢 Ativa |
| **Redes & Cloud** | Fundamentos de redes, AWS Academy, infraestrutura como código | 🟢 Ativa |
| **Monitoramento** | Zabbix + Grafana em Docker | 🟡 Em breve |

### 🚀 Como participar

1. Crie sua conta em [github.com](https://github.com) e peça o [GitHub Student Developer Pack](https://education.github.com/pack).
2. Aceite o convite da atividade enviado pelo professor (GitHub Classroom).
3. Abra o repositório no **Codespaces** e comece, sem instalar nada.
4. Entregue com `git push` e acompanhe o feedback no pull request.
